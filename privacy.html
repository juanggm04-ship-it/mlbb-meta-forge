Política de privacidad

En la versión actual no usamos Google Analytics, píxeles publicitarios ni trackers de terceros para perfilarte.

Datos guardados en tu dispositivo

Meta Forge puede usar almacenamiento local del navegador para funciones como Watchlist, preferencias de perfil, historial local de drafts, comparaciones recientes y actividad reciente. Esa información se guarda en tu dispositivo y no se envía a un servidor propio de Meta Forge.

Uso sin conexión y Cache Storage

El sitio puede registrar un service worker y usar Cache Storage para conservar páginas, recursos y snapshots públicos recientes. Esto permite abrir partes de Meta Forge con conexión inestable o sin conexión. El caché no se utiliza para publicidad personalizada.

Alojamiento y datos técnicos

Meta Forge se publica mediante GitHub Pages. Como ocurre con otros servicios de alojamiento, GitHub y la infraestructura que entrega el sitio pueden recibir datos técnicos necesarios para prestar el servicio, como dirección IP, agente de usuario, fecha y hora de acceso o solicitudes de recursos, de acuerdo con sus propias políticas.

Recursos y servicios externos

Algunas páginas pueden cargar imágenes, fuentes de datos o enlaces desde servicios externos. Cuando el navegador solicita un recurso externo, ese proveedor puede recibir información técnica básica necesaria para entregar el contenido. Meta Forge no controla las políticas de esos terceros.

Cookies y analítica

Actualmente no instalamos cookies publicitarias ni de analítica. Si en el futuro se activan medición, publicidad o tecnologías no esenciales, esta política y el mecanismo de consentimiento se actualizarán antes de cargarlas cuando corresponda.

Tu control

Puedes eliminar Watchlist, preferencias, historial y caché borrando los datos del sitio desde la configuración de tu navegador. También puedes usar Meta Forge sin crear una cuenta.

Cambios y contacto

Esta política puede cambiar cuando cambien las funciones del sitio o los servicios utilizados. Si detectas un problema de privacidad, puedes abrir un reporte en GitHub.
